배포 안내

1. GitHub 소스 교체 시 이 폴더의 src, public, scripts와 설정 파일을 같은 경로에 덮어씁니다.
2. dist 배포 방식이면 이 폴더의 dist 전체를 배포합니다.
3. 이번 3차DB 업데이트는 Apps Script 교체가 필요 없습니다.

적용 내용
- 원본의 로켓방문요청 값이 저장된 '컨설팅타입' 칼럼을 기준으로 수정
- 컨설팅상태가 로켓방문요청인 연락처를 3차DB(방문상담)로 표시
- 견적확인 후 바로 방문신청 / 상담신청 후 방문신청 / 이전 경로 확인 불가 분리
- DB관리 3차DB 탭 및 방문신청 일시 표시
- 퍼널 분석에 3차DB와 매체별 3차 전환 추가
- 전체 DB, CPL, API는 기존 연락처 중복 제거 및 2차 포함 기준 유지

최신 컨설팅리스트 검산
- 로켓방문요청 원본 행: 42건
- 연락처 중복 제거 후 3차DB: 31건

방문 경로 수정
- 등록일시의 YYYY/MM/DD 형식까지 정확하게 시간순 정렬
- 방문요청 전에 로켓견적확인 이력이 있으면 '알림톡 무료방문상담 신청'으로 우선 분류
- 최신 원본 기준: 알림톡 신청 23건, 상담신청 후 방문신청 8건, 이전 경로 확인 불가 0건
- 최미용: 알림톡 무료방문상담 신청으로 검산 완료

메인 대시보드 상단 요약 탭
- DB 현황 / 계약 현황 탭 전환 추가
- 선택한 탭은 현재 브라우저 세션에서 유지
- 계약 현황: 선택기간 계약, 계약금액, 이전기간 계약, 누적 계약, 계약 전환율, 계약당 광고비
- 일별은 오늘/어제, 주·월·연·기간별은 선택기간/이전 동일기간에 맞춰 자동 표기
- 모든 DB·계약 카드에 집계기간, 제외 조건, 계산식 툴팁 반영
- 계약은 계약금입금일 기준 고유 프로젝트이며 취소·삭제·테스트·중복·무효 제외
- 기존 DB 수치·CPL·1→2 전환율 공식과 업로드 방식은 변경하지 않음
