프로젝트 업로드 후 오늘 계약 즉시 반영 수정본

원인
- 프로젝트 업로드 후 프로젝트 원본 캐시는 갱신됐지만 계약 요약 캐시가 남아 이전 계약 건수를 표시했습니다.
- 상단 새로고침 버튼도 캐시를 비우지 않아 같은 값이 다시 표시될 수 있었습니다.

수정 내용
- 프로젝트 업로드 완료 시 계약 요약 캐시도 즉시 삭제합니다.
- 계약 요약은 브라우저 로컬 캐시에 장기 보관하지 않습니다.
- 대시보드 새로고침 버튼은 캐시를 먼저 비운 뒤 최신 데이터를 조회합니다.

적용 방법
1. dist 폴더를 Vercel에 재배포합니다.
2. 배포 완료 후 대시보드를 한 번 새로고침합니다.

Apps Script
- 직전 계약 forbidden 수정본의 APPS_SCRIPT_CODE.txt를 이미 새 버전으로 배포했다면 다시 교체할 필요 없습니다.
